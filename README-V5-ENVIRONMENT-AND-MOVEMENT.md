# One Piece: Grand Line — V5 Environment & Movement Pass

V5 continues from the V4 project rather than rebuilding it.

## Changes in this pass
- Increased default jog and sprint speeds while retaining a slower walk mode.
- Added direct pace selection: `Z` = Walk, `X` = Jog, `B` = Sprint. `V` still cycles through all three modes and `Shift` remains a temporary sprint modifier.
- Expanded vegetation exclusion zones around Foosha Village, its main footpath and dock approach, and Loguetown's central town footprint. Trees, ground cover, bushes, rocks, mounds and flowers now share the same exclusion test.
- Reused the rock material across procedural rock instances to reduce unnecessary material creation.
- Updated the browser module cache version.

## Visual direction
Apex Legends is a reference for environmental fidelity, not a source of copied assets. External assets should be added only when their individual licenses permit redistribution in the browser project. Poly Haven assets are CC0 according to its license page.

## Validation
Syntax and archive integrity checks are run before packaging. A real browser/WebGL visual playtest remains necessary for final confirmation.
